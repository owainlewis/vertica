# Geist

Unmodified variable WOFF2 fonts from [vercel/geist-font](https://github.com/vercel/geist-font/tree/10dc7658f13c38a474cde201bb09a4617267545b/fonts/Geist/webfonts), pinned to commit `10dc7658f13c38a474cde201bb09a4617267545b`.

- `Geist[wght].woff2` is stored as `Geist-Variable.woff2`.
- `Geist-Italic[wght].woff2` is stored as `Geist-Italic-Variable.woff2`.
